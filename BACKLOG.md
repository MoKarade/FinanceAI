# BACKLOG — FinanceAI

Le backlog vit dans les **issues** du dépôt : <https://github.com/MoKarade/FinanceAI/issues>.
Ce fichier n'en garde qu'un renvoi (décision du 15/10/2026, plan de standardisation) : une liste tenue
à deux endroits dit deux choses différentes au bout d'une semaine.

- Une tâche = une issue `niveau:tâche`, avec **Avant**, **Après** et **Fini quand**.
- Ce qui est livré se lit dans `HANDOVER.md` (état réel) et dans l'historique git.
- L'ancienne liste (jusqu'au 15/10/2026) est conservée telle quelle dans
  [`docs/BACKLOG_AVANT_ISSUES_2026-10-15.md`](docs/BACKLOG_AVANT_ISSUES_2026-10-15.md) : les lignes
  « Source : BACKLOG.md:Lnn » des issues renvoient à CE fichier-là.
- Items finis avant cette date : [`docs/BACKLOG_ARCHIVE.md`](docs/BACKLOG_ARCHIVE.md). Gestes de Marc : [`docs/A_FAIRE_MOI.md`](docs/A_FAIRE_MOI.md).
