## Les 🔴 prioritaires, expliqués

- **`[FISC-DIVORCE-INCOME-PHANTOM]`** — le divorce coupe les actifs (60 832 → 33 928 $ mesuré) mais
  garde le salaire de l'ex ET la fiscalité de couple : ~**85 000 $/an de revenu fantôme**.
- **`[ENG-STRESSTEST-GROWTH-UNREGISTERED]`** — krach + reprise mutent les soldes hors de tout
  registre de croissance : **371 782 $ créés en 20 mois**, krach de −589 644 $ absent des flux,
  invariant de bilan resté vert à 0,010 $ (garde circulaire : elle ne regarde pas là).
- **`[ENG-DIVORCE-DEBT-ASYMMETRY]`** — `splitPct=100` cède 100 % des actifs et garde **100 % des
  dettes** : patrimoine mesuré à **−81 827 $**. Symétrique : à `splitPct=0` le divorce est
  strictement inerte (Δ impôts = 0,00 $) alors que le décès, lui, fusionne bien les registres
  (`[ENG-DIVORCE-REGISTRE-PERCONJOINT]`).
- **`[ENG-MC-CONSERVATION-BLIND]`** — toute la branche stochastique est hors filet : probabilités
  forcées à 1 → 0 divorce, 0 soins de longue durée, 0 maladie grave, 0 héritage, 0 décès dans le
  `chartData` déterministe sur 361 mois ; le point MC n'expose que `{NetWorth, monthIndex}`.
- **`[ENG-W5-RENTAL-OFFBALANCE]` / `[ENG-W5-BUSINESS-OFFBALANCE]`** — immeuble 800 k$ (hypothèque
  500 k$) et entreprise 2 M$ absents du bilan, invariant vert à 0,020 $.
- **`[FISC-DON-ABATEMENT]`** — crédit fédéral pour dons non réduit de l'abattement québécois
  16,5 % : sur-crédit **234,63 $/an** (dons 5 k$), **952,38 $/an** (dons 20 k$).
- **`[A11Y-PRIVACY-*]` (5 findings)** — le **mode discret laisse des montants lisibles** dans
  Dettes, Impôts, import de talon, Retraite (répartition d'actifs) et totaux de Transactions,
  alors que ces mêmes écrans masquent DÉJÀ d'autres champs.
- **`[AI-VISION-PAYSLIP-NOGATE]` + `[AI-PAYSLIP-SCHEMA-UNBOUNDED]`** — l'import de talon écrit le
  salaire directement dans le profil : ni confirmation, ni backup, ni garde ; et le schéma accepte
  `Infinity` et les négatifs (le reste du dépôt impose `.positive().finite()`). Le même import via
  le chat exige diff + modale + backup : c'est l'incohérence qui est le bug.
- **`[SILENT-ACTIONPLAN-NAN]`** — le « Plan d'action » convertit une valeur non finie du moteur en
  **0 $** sans trace, alors que ses modules frères journalisent ce cas.

## Hypothèses RÉFUTÉES — ne pas les re-lever

Ces pistes ressemblaient à des bugs et n'en sont pas. Elles sont consignées pour éviter de
repayer cet audit :

1. **« Les dons sont un no-op »** — faux : le crédit est bien câblé (seul l'abattement manque).
2. **« Le stress-test suit l'année calendaire »** — faux : il utilise un offset d'années (défaut 5).
3. **« Le divorce casse Σ(reerByUser) »** — faux : `stepReerByUser` réconcilie chaque mois.
4. **« `realEstateEquity` re-soustrait `mortgageBalance` »** — faux : aucune double soustraction.
5. **« `shortfallRate` ≈ 1 pour tout retraité »** — faux : mesuré 0,211 sur un retraité aisé.

À noter : l'agent moteur a **réfuté deux de ses propres sondes** erronées avant de conclure —
c'est la discipline attendue (un finding money-critical est une hypothèse tant qu'il n'est pas
reproduit).
